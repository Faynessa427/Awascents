# Awascents

Awascents is a frontend fragrance store built with HTML, CSS, and JavaScript.

## Features

- Luxury fragrance homepage with a perfume slideshow
- Fresh/Airy, Luxurious, and Signature product collections
- Product videos and fragrance imagery
- Add-to-cart functionality using browser `localStorage`
- Automatic cart loading when a product is selected from the homepage
- Order summary and order form
- Contact, About, Feedback, and Terms of Use pages
- Responsive layout for desktop and mobile screens

## Pages

- `index.html` - Homepage and featured best sellers
- `visit.html` - Fragrance store and shopping cart
- `order.html` - Order summary and checkout form
- `about.html` - About Awascents
- `contact.html` - Contact form and contact details
- `response.html` - Contact form confirmation
- `terms.html` - Terms of Use
